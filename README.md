# Opdracht 1 — Vast IP-adres op een Raspberry Pi (network-config)

`rpi_static_ip.sh` zet een `network-config`-bestand (cloud-init / Netplan v2, YAML) in de root van de
boot-partitie van een Raspberry Pi OS SD-kaart. Bij de eerste opstart geeft cloud-init de Pi daarmee een vast IP-adres.

> De opgave vraagt PowerShell (`rpi_static_ip.ps1`). Dit script draait op een Linux-laptop en is daarom in bash
> geschreven; het doet hetzelfde.

## Gebruik

```sh
# SD-kaart insteken (gemount of niet), dan:
./rpi_static_ip.sh -a 192.168.1.50/24 -g 192.168.1.1
./rpi_static_ip.sh -a 192.168.1.50/24 -g 192.168.1.1 -d 192.168.1.2,192.168.1.3 -i eth0
./rpi_static_ip.sh -a 192.168.1.50/24 -g 192.168.1.1 --dry-run        # enkel tonen
./rpi_static_ip.sh -a 192.168.1.50/24 -g 192.168.1.1 -b /pad/naar/bootfs
```

| optie | betekenis | standaard |
|---|---|---|
| `-a`, `--address` | IP-adres met prefix | verplicht |
| `-g`, `--gateway` | default gateway | verplicht |
| `-d`, `--dns` | DNS-servers, komma-gescheiden | `1.1.1.1,8.8.8.8` |
| `-i`, `--interface` | netwerkinterface | `eth0` |
| `-b`, `--boot-dir` | map van de boot-partitie (sla detectie over) | automatisch |
| `-n`, `--dry-run` | YAML tonen zonder te schrijven | |

## Hoe het de eisen invult

- **Boot-partitie zoeken** — zoekt de partitie met label `bootfs` (`blkid -L bootfs`, met `lsblk` als reserve).
  Is ze nog niet gemount, dan mount het script ze met `udisksctl` (geen root nodig). Als extra veiligheid weigert het
  een map zonder `config.txt`/`cmdline.txt`, zodat het nooit op de boot-partitie van je eigen laptop schrijft.
- **Linux-tekstbestand** — het bestand wordt met `printf` geschreven: UTF-8 zonder BOM en enkel `LF` als regeleinde.
  Een bestaand bestand met `CRLF` wordt altijd vervangen.
- **Niet bevuilen bij meerdere keren uitvoeren** — het script genereert telkens het *volledige* bestand en vergelijkt
  het met wat er staat: is het gelijk, dan verandert er niets; anders wordt het volledig vervangen (nooit aangevuld).
  Het originele bestand (bv. van Raspberry Pi Imager) wordt één keer bewaard als `network-config.orig`.
  Het schrijven gebeurt via een tijdelijk bestand + `mv`, zodat een onderbroken run geen half bestand achterlaat.
- **Invoercontrole** — ongeldig IP, prefix, DNS-server of interface, of een gateway buiten het subnet, stopt het
  script met een foutmelding.

## Voorbeeld van het resultaat

```yaml
# Generated by rpi_static_ip.sh - static IP for eth0
network:
  version: 2
  ethernets:
    eth0:
      dhcp4: false
      addresses:
        - 192.168.1.50/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses:
          - 1.1.1.1
          - 8.8.8.8
      optional: true
```

## Opmerking

cloud-init past `network-config` toe bij de **eerste** opstart van een image. Is de Pi al eens opgestart met deze
kaart, dan leest cloud-init het bestand pas opnieuw als de `instance-id` in `meta-data` op dezelfde partitie verandert.
